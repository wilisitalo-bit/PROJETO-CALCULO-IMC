# ⚖️ Calculadora de IMC

## 📌 Sobre o projeto

A **Calculadora de IMC** é uma aplicação web desenvolvida para calcular o Índice de Massa Corporal (IMC) a partir do peso e da altura informados pelo usuário.

O projeto foi desenvolvido com o objetivo de praticar lógica de programação e desenvolvimento web, utilizando HTML, CSS e JavaScript.

A aplicação realiza o cálculo automaticamente e apresenta o resultado acompanhado de uma classificação correspondente à faixa de IMC.

## 🚀 Funcionalidades

* Inserção do peso em quilogramas (kg).
* Inserção da altura em metros (m).
* Cálculo automático do Índice de Massa Corporal.
* Validação dos campos obrigatórios.
* Validação de valores positivos.
* Exibição do resultado com duas casas decimais.
* Classificação automática do IMC.

## 📊 Classificação do IMC

| IMC            | Classificação     |
| -------------- | ----------------- |
| Abaixo de 18,5 | Abaixo do peso    |
| 18,5 a 24,9    | Peso ideal        |
| 25 a 29,9      | Sobrepeso         |
| 30 a 34,9      | Obesidade         |
| 35 a 39,9      | Obesidade severa  |
| 40 ou superior | Obesidade mórbida |

*Observação: as classificações apresentadas são referências gerais para adultos e não substituem uma avaliação profissional de saúde.*

## 💻 Tecnologias utilizadas

* HTML5 (estrutura da página).
* CSS3 (estilização e layout).
* JavaScript (lógica de programação, validações e cálculo do IMC).
* Portugol.
* Visualg (ambiente para execução de algoritmos).

## 🖥️ Como executar o projeto

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto.
3. Localize o arquivo `index.html`.
4. Abra o arquivo em um navegador de sua preferência.
5. Informe seu peso e sua altura.
6. Clique em **Calcular IMC** para visualizar o resultado.
