# ⚖️ Cálculo de IMC Aninhado

## 📌 Sobre o projeto

Este projeto consiste em um algoritmo desenvolvido em **Portugol**, com o objetivo de calcular o Índice de Massa Corporal (IMC) de uma pessoa a partir de seu peso e altura.

Após realizar o cálculo, o algoritmo apresenta o resultado e classifica o IMC de acordo com faixas de referência, utilizando estruturas condicionais aninhadas (SE / SENÃO).

## ⚙️ Funcionalidades

* Solicita o peso do usuário em quilogramas (kg).
* Solicita a altura em metros (m).
* Calcula o Índice de Massa Corporal.
* Exibe o resultado com duas casas decimais.
* Classifica o resultado conforme a faixa de IMC.

## 🧮 Fórmula utilizada

O cálculo do IMC é realizado utilizando a seguinte fórmula:

**IMC = Peso / (Altura × Altura)**

## 📊 Classificação utilizada

| Resultado do IMC | Classificação     |
| ---------------- | ----------------- |
| Menor que 18,5   | Abaixo do peso    |
| 18,5 até 24,9    | Peso ideal        |
| 25 até 29,9      | Sobrepeso         |
| 30 até 34,9      | Obesidade         |
| 35 até 39,9      | Obesidade severa  |
| 40 ou mais       | Obesidade mórbida |

*Observação: as faixas representam a classificação simplificada utilizada no exercício, não substituindo uma avaliação profissional de saúde.*
